# M2 Qwen 全 60 层 I/GT 差异图筛选说明

## 实验口径

- 数据：纠正标签后的 M2 训练集。
- 样本：固定种子 2026，从五种长宽比分组各取一张。
- 模型：冻结的基础 Qwen-Image-Edit-2509。
- LoRA：全部关闭。
- VAE：posterior mode，避免随机采样噪声。
- timestep：499。
- 特征：每个 Transformer block 输出的 image stream。
- 热点：逐 token 计算 `1-cosine(Q_l(I), Q_l(GT))`。
- 层编号：图中的 block 01–60 是人类习惯的一基编号。

## 文件

每个样本有三类图：

1. `<id>_references.png`
   - 原图 I、GT、像素差、DoLP，仅供定位场景内容。
2. `images/<id>_all60_shared_heat.png`
   - 同一张样本的 60 层共用一套 p02/p98 色标。
   - 用于比较各层响应绝对强弱。
3. `images/<id>_all60_local_overlay.png`
   - 每一层分别做 p02/p98 归一化后叠加到原图。
   - 用于比较热点的空间位置，不能比较不同层的强度。

未归一化的 float32 差异图保存在 `raw_maps/<id>_all60.npz`。

## 筛选标准

对候选层按以下五项判断，每项 0–2 分，并要求在至少 4/5 张图上表现稳定。

1. **反射召回**：GT 中被移除或减弱的反射主体是否得到连续响应。
2. **空间精度**：热点是否落在真实变化区域，是否扩散到无关背景。
3. **内容保持**：未变化的物体、文字笔画和细纹理是否保持低响应。
4. **伪响应抑制**：是否只在普通边缘、亮度变化或轻微配准误差处响应。
5. **跨场景稳定性**：不同长宽比和场景下是否表现一致。

先看 shared heat 排除几乎无响应或全局饱和的层，再看 local overlay 判断空间模式。

## 解释限制

这些图只表示 I 与 GT 在冻结特征中的差异。热点对准反射区域，并不能单独证明该层理解了反射语义。最终候选还需要使用 I、P90 和 GT 的关系、低变化区保持能力，以及等预算训练对照进一步验证。
