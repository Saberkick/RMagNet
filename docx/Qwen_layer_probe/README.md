# Qwen 三层差异图人工筛选说明

本实验从 M1b/M1c 的 50 张训练图中用 Python `random.Random(2026).sample` 固定抽取 5 张，验证图 11、12、17 不参与。基础 Qwen 的全部 LoRA 被关闭，VAE 使用确定性的 posterior mode；因此热图不会混入 I 与 GT 两次独立 latent 采样造成的随机差异。

候选层为 60 个 DiT block 后的第 20、30、40 层，分别代表主干约 1/3、1/2、2/3 深度。每个位置计算 I 和 GT 图像 token 的余弦距离。每张样本的三个候选层使用同一组 2%/98% 显示上下限，因此同一行内颜色强弱可以比较；不同样本之间的颜色强弱不能直接比较。原始 float32 24×32 差异保存在 `raw_maps/`，没有经过显示归一化。

## 筛选标准

请先看 `SUMMARY_5x3_OVERLAYS.png` 的五行总览，再看单图热图和 references。

按以下顺序判断：

1. **反射区域召回。** GT 中被消除或明显减弱的反射主体、反射边缘和遮挡处应有连续高响应。漏掉大块明显反射的层不选。
2. **空间精度。** 高响应应落在真实发生变化的位置，边界不应扩散到大片无关背景。24×32 token 网格本身会造成约 16×16 像素级的平滑，不要求像素级锐利。
3. **文字与细纹理。** 在玻璃后的文字、细线、织物或重复纹理中，响应应覆盖被反射破坏且 GT 恢复的部分，同时尽量保留未发生变化的笔画和纹理。
4. **伪响应。** 对 I/GT 配准小误差、曝光或白平衡变化、普通物体轮廓、纯色平坦区域的整片响应越少越好。尤其注意热图是否只是复刻所有边缘。
5. **跨样本稳定性。** 至少 4/5 张图呈现相同优点。不要因某一张特别漂亮就选层。
6. **适度保留局部细节。** 过浅层若几乎只响应颜色和边缘差，语义不足；过深层若只剩大块物体级热点并丢失文字笔画，空间分辨率不足。优先选择能覆盖反射主体，同时仍保留局部结构的一层。

建议对每层在每张图记录 0–2 分：反射召回、空间精度、文字/纹理、伪响应四项，总分 40。伪响应项中“少”得高分。若最高两层相差不超过 3 分，先保留两层，下一步做小规模梯度和显存试验，不要现在强行单选。

注意：这些图利用了训练期 GT，只用于选择监督特征层；不能作为推理输入，也不能证明 Qwen 理解了反射。差异图可能同时包含相机位移、曝光变化和偏振导致的非反射外观差异。
