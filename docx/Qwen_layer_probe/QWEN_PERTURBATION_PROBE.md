# Qwen 全层受控扰动诊断

## 目的

验证“前段层适合纹理保持”的假设，并区分局部视觉敏感性、全局混合和末段重新聚焦。

## 实验设置

- 数据版本：纠正标签后的 M2。
- 基准图：`96_2492_938`，包含招牌文字、玻璃、边缘和细纹理。
- 对象替换供体：`69_2200_1512`。
- 模型：冻结基础 Qwen-Image-Edit-2509，全部 LoRA 关闭。
- VAE：确定性 posterior mode。
- timestep：499。
- 特征：block 1–60 的 image stream。
- 距离：`1-cosine(Q_l(base), Q_l(perturbed))`。

四类扰动：

1. 局部玻璃区域 Gaussian blur，半径 7。
2. 在招牌文字上删除七段狭窄笔画。
3. 全局亮度乘 1.06，RGB 增益为 `[1.05,1.00,0.95]`。
4. 将另一个场景的局部内容柔和贴入上方玻璃区域。

## 指标

- `inside_outside_ratio`：扰动区域内平均响应与外部平均响应之比。
- `response_energy_inside_mask`：总响应中留在扰动区域的比例。
- `normalized_spatial_entropy`：响应空间扩散程度，越高越分散。
- `mean`：该层对扰动的总体响应强度。

## 结果

### 1. 前段层确实最具空间局部性

| Block | 模糊内外比 | 笔画内外比 | 对象替换内外比 |
|---:|---:|---:|---:|
| 1 | 134.98 | 46.97 | 53.81 |
| 8 | 59.39 | 43.34 | 40.77 |
| 12 | 39.22 | 40.01 | 30.64 |
| 16 | 26.93 | 37.15 | 23.20 |
| 20 | 26.52 | 37.50 | 21.24 |
| 32 | 11.37 | 23.08 | 11.75 |
| 40 | 6.34 | 10.58 | 6.19 |
| 52 | 14.81 | 21.10 | 13.26 |
| 56 | 9.05 | 21.28 | 15.03 |

局部模糊的响应能量在 block 1 中有 93.4% 留在扰动区域，随后逐层下降。说明前段层的主要优势是空间局部性。

### 2. 中间层响应最强，但也最分散

局部模糊的平均响应在 block 39 达到最大；删除笔画在 block 41 最大；对象替换在 block 37 最大。相同区域的空间熵也在约 block 37–43 达到高位。

这说明中间层强烈传播所有变化，符合“全局关系混合”的特征，但不能仅凭强响应认定它是反射语义层。

### 3. 中间层也最容易受到曝光和白平衡影响

全局曝光/白平衡扰动的最大响应同样出现在 block 37–41。中层对对象替换敏感的同时，也对普通光度变化敏感，因此后续语义损失必须加入光度不变性对照。

### 4. 末段出现重新聚焦，但 block 60 不适合作为候选

约 block 48–58 的局部内外比重新上升、曝光响应降低，与人工观察到的末段热点重新集中一致。

block 60 对模糊、笔画和曝光的绝对响应接近零，容易产生不稳定的归一化热图，不建议选择最终 block。

## 当前结论

“前段用于纹理保持”的假设得到部分支持：

- 得到支持的是：前段对局部扰动的响应最集中，适合限制无关区域被重绘。
- 尚未证明的是：最浅层是否包含足够的文字或纹理身份。block 1–8 虽然最集中，但更可能只是低级变化检测。

更合适的首轮候选为：

- **纹理保持：block 16 与 block 20。** 比最浅层有更高的笔画响应，同时仍有较强空间局部性。
- **语义关系：block 37、39、41。** 对对象替换响应最强，但必须用曝光对照约束，避免把光度敏感性当成语义。
- **末段定位：block 52、54、56。** 观察重新聚焦区间，避开响应退化的 block 60。

## 限制与下一步

本实验只使用一个主场景，且对象替换是合成贴入。它足以验证层深度与空间扩散的规律，但不能单独决定最终层。

下一步应在刚才五张 I/GT 样本上，对候选集合 `{16,20,37,39,41,52,54,56}` 做同样扰动，并计算跨场景均值和方差，然后再确定用于 texture、semantic 与 gate 的最终层。
