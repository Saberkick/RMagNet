## 人工核对与分析（2026-10-09）

### 是否确实完成联合训练

完整流程退出码为 0，完成 204 次更新及 best/latest 在 test26、real20 上的四项评估。best 为第 2 epoch（step 102），latest 为第 4 epoch（step 204），选择依据是验证集保存后 PNG 的平均 L1，未使用测试集选权重。训练日志累计用时约 46.6 分钟，另有模型启动和最终评估开销。

204 次更新均记录了学生 LoRA 与 readers 的非零梯度，并通过首步参数变化和冻结模块检查。全部训练样本使用正确配对 GT。因此，本轮已实现语义读取模块与编辑 LoRA 的联合优化；负结果不能解释为“编辑 LoRA 没有训练”。

### 收益是否稳定

- test26：B4-best 的 PSNR 在 14/26 张上超过 M4，中位变化 +0.0146 dB，均值 +0.0235 dB；SSIM 也是 14/26 张胜出，但均值略降。LPIPS 从 0.159256 增至 0.160032。这属于混合且很小的变化，不能据此宣称整体超过 M4。
- real20：B4-best 仅 2/20 张 PSNR 胜出，中位变化 -0.1603 dB；latest 仅 3/20 张胜出。外部数据的退化较为普遍，不只是单张异常拉低平均值。
- 旧测试子集 17 张：B4-best PSNR/SSIM 为 24.1725 / 0.839675，M4 为 24.1575 / 0.839333。
- 新测试子集 9 张：B4-best 为 24.4224 / 0.723518，M4 为 24.3829 / 0.724715。PSNR 与结构质量没有同步改善。
- 用户此前关注的 real20-22：M4 / B4-best / B4-latest 为 26.8463 / 26.6297 / 26.2277 dB；real20-47 为 26.0115 / 25.6265 / 25.1719 dB。指标未支持这两张的改进；局部观感应另看已保存 panel。

### 当前证据支持什么

训练集普通输入重建项的 epoch 均值由 0.07128 降至 0.06423，P90 重建项由 0.10922 降至 0.09719；验证 PSNR 在第 2 epoch 达到 24.2639 后降至第 4 epoch 的 24.1768。训练拟合继续改善而验证收益回落，符合早期过拟合或分布适应的迹象，但四个 epoch 尚不足以单独确定机制。

固定教师辅助梯度与基础梯度在输出空间的合成范数比，第 2—4 epoch 平均约为 19%；这不是逐参数的语义梯度占比，且空间、纹理、语义三项合并统计，不能据此断言语义项已经足够强。

可能的机制包括：204 张训练图对约 8.52 亿 LoRA 参数的约束有限；联合更新改变 Q37 特征分布，而固定语义记忆/PCA 仍建立在 M4 表示上；重建和特征相似目标并未直接标注语义读取是否正确、编辑是否有害。这些均为待验证假设，当前日志没有证明其中哪项是主因，也没有证明选层错误。

### 下一步决策

本轮不建议直接延长 B4 训练；第 2 epoch 已优于第 4 epoch，且 real20 全面收益不足。保留 M4-best 为当前主要基线，B4-best 留作联合优化参考。

如继续，应先用同初始化、同预算的“仅 LoRA”A4及“冻结 LoRA、只训练 readers”S4区分收益来源，再验证 C 中的条件化 LoRA 与可靠性门控。C 的价值仍是设计假设，B4 的结果并未验证 C。所有后续调参应使用验证集；本轮封存测试结果用于汇报，不作为反复筛选配置的依据。
