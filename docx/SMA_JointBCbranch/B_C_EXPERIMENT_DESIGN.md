# SMA 联合编辑实验 B 与语义条件编辑实验 C

## 1. 问题与已有证据

冻结 M4 LoRA 并不阻断 SMA 到图像的梯度：读取模块改变隐藏特征后，冻结后续层仍会改变输出。但原方案只能让读取模块适应固定编辑路径，无法让编辑路径适应新增语义。

合并数据 SMA 50 epoch 的 best 在 epoch 2。26 张封存测试：M4-best 24.2355 dB / 0.799657，SMA-best 24.2529 / 0.799126，latest 23.8461 / 0.801128。real20 同口径 mode 编码：M4-best 25.5068 / 0.819492，SMA-best 25.3860 / 0.818244，latest 24.3799 / 0.806105。没有稳定泛化收益，长训练退化。因此本轮先做 4 epoch 方向探针，不将延长训练当作解决方法。

这些结果不能证明失败原因是冻结 LoRA，也不能证明抽取层一定正确。需通过控制实验区分。

## 2. 固定数据与评价协议

- 合并后的纠正标签数据：`/share/linmingheng-local/xuke/datasets/rmagnet_sma_dataset2`。
- 204 train / 26 validation / 26 sealed test，原有拍摄分组划分与长宽比不变。
- 复用 `data_cache/sma_dataset2_v1`，其教师必须始终是固定 M4-best，不能随学生 LoRA 更新。
- 初始化 M4 SHA-256：`897282b1bb9cfe61f96530df72edcf8a44a066bb819a3663e9100862aefdb2a3`。
- 所有实验从 M4-best 与相同预训练语义记忆出发，不从 SMA50 的已训练读取模块续训。
- VAE posterior mode；BF16 主干，NF4 存储；逐图 batch=1，4 GPU，累积=1，有效 batch=4。
- 每 epoch 完整遍历 204 张一次，无补齐/丢弃：51 更新；4 epoch=204 更新。
- 每 epoch 评估 26 张验证集，按保存后 RGB8 PNG 宏平均 L1 选择 best。同时保存 latest，保留初始化基线指标。
- 封存测试仅用于完成训练后的报告，不用于挑选 epoch、学习率或损失系数；分开报告旧17、新9。
- 测试只输入普通 I。GT 仅计算指标，不输入 P90、DoLP、训练缓存。
- 测试主指标 PSNR、SSIM、L1、LPIPS-SqueezeNet，并报告低变化保持/高变化恢复误差。real20 作为外部迁移评价，使用官方短边分块和原始尺寸 PNG。

## 3. 实验 B：联合训练学生 LoRA 与原有 SMA 读取模块

### 3.1 可训练边界

| 组件 | 状态 |
|---|---|
| Qwen 主干原始权重、VAE | 冻结 |
| 学生 Transmission LoRA | 全部训练，从 M4-best 初始化 |
| Q39/Q41 SMA 读取模块 | 训练，输出投影零初始化 |
| Q37 PCA 与预训练语义记忆 | 冻结，沿用原方案 |
| 语义监督教师 | 独立固定 M4-best，SMA 旁路 |

保留原来的 memory detach/no-grad 路径：B 不改变语义记忆训练策略。LoRA 仍通过主干编辑路径和读取模块的 query 路径接收梯度。固定记忆可能遇到学生 Q37 表示漂移，这属于本轮待观察的限制，不通过同时重训记忆掩盖。

### 3.2 损失保持不变

$$
L_{rec}(Y,G)=L_1(Y,G)+0.2[1-SSIM(Y,G)]+0.1L_{edge}(Y,G)
$$

$$
L_{base}=\frac{L_{rec}(F(I),GT)+L_{rec}(F(P90),GT)}{2}+0.10L_{polar}
$$

`L_polar` 保留。代码使用 I/P90 双向 stop-gradient 一致性求导。普通 I 分支额外加入以下三项输出梯度，P90 分支保持基础监督：

- 空间项：0.75 加权 Charbonnier 恢复 + 0.25 低响应保持；晚层 Q52/Q54/Q56 生成固定 gate。
- 纹理项：Q16/Q20，gate 外对齐输入、gate 内对齐 GT。
- 语义项：Q37/Q39/Q41，0.7 中心化内容 + 0.3 邻接关系。

$$
g_I=g_{base,I}+c\sum_{k\in\{spatial,texture,semantic\}}\lambda_k g_k
$$

各辅助项目标输出梯度范数为基础项的 8%，前36更新渐入，EMA=0.9，系数截断 `[1e-4,10]`，合并辅助输出梯度上限25%。这是输出空间的梯度控制，不代表每个参数组都具有相同梯度比例；日志另记 LoRA 与读取模块实际梯度范数。

### 3.3 优化与资源

- 读取模块 AdamW：LR=1e-4，weight_decay=0.01，FP32 状态。
- 学生 LoRA：LR=5e-6，沿用既有 LoRA 训练的 PagedAdamW8bit，优化器状态在更新后卸载 CPU。
- 两组均 warmup20 更新 + 204 更新范围内 cosine；联合全局梯度裁剪1.0。
- 无早停，完整运行4 epoch，以避免不同预算；只保留 best/latest 联合权重，不保存优化器。
- 固定教师 LoRA 驻留 CPU；在预测输出叶子上计算教师 VJP 时暂存学生权重、加载固定教师，VJP 完成后恢复学生，再重算生成路径反传。任何学生图或教师图都不能跨越权重切换继续反传。
- 不额外加载一整份 DiT，不在 GPU 常驻另一份3.25GB教师 LoRA。最多使用GPU0–3，不触碰4–7。
- 联合 checkpoint 必须包含学生 LoRA 和完整 SMA，不能只保存读取模块后重新套到固定 M4 上。

### 3.4 最小验收

1. 四个 rank 均加载同一 M4，数据配对及缓存哈希通过。
2. 原始主干/VAE/记忆参数无梯度，固定教师不进入优化器。
3. LoRA 与读取模块梯度有限、非零，首次更新后均有参数实际变化。
4. 教师输出使用固定 M4，预测特征与缓存保持同一坐标系。
5. 一步试跑可保存联合 checkpoint，重新加载后复现保存时的验证 PNG。
6. 正式训练从 M4/fresh readers 重新开始，不能从试跑 checkpoint 开始。
7. 四次验证与204次更新完成后，评估 best/latest 的26张封存测试。

### 3.5 对照与结论边界

- 固定 M4-best：判断是否获得实际收益。
- 历史 SMA50 epoch1–4：仅作训练方向参考。其 cosine 总长度2550步，本轮204步，学习率轨迹不同，不能宣称严格同预算因果对照。
- 严格 S4：同初始化、相同204步/读取LR/损失，只冻结 LoRA，才能隔离“解冻编辑路径”的影响。
- 严格 A4：仅训练 LoRA、旁路 SMA，但其余损失/LoRA LR/更新次数相同，才能区分收益来自普通续训还是语义模块。

本次先实施 B4，交付结果时明确哪些对照实际运行，不能把历史50 epoch曲线当作 S4/A4已完成。4 epoch 阴性结果只说明此设置无收益，不能排除学习率/表示选择的影响。

## 4. 实验 C：语义条件编辑与错误引导抑制（本次设计，不启动）

### 4.1 将语义直接接入编辑通道

B 先验证联合优化，不改变 SMA 的注入位置。C 再将空间语义 C(x) 接入 LoRA 的低秩编辑通道，保留完整语义向量，不把它全部压缩成一个 mask。

$$
z_l(x)=A_l h_l(x)
$$

$$
\Delta h_l(x)=B_l\left[\left(1+\alpha_l g_l(x)\tanh U_l(C(x))\right)\odot z_l(x)\right]
$$

- A/B 从 M4 LoRA 初始化并参与训练。
- Q37 提取空间语义，用小型可训练投影得到 C；第一轮保留已有冻结语义记忆，避免重训一个大语义网络。
- 第一版只在 Q39/Q41 的图像 token FFN 线性层接入条件调节，暂不修改混合文本/图像 attention 的 Q/K。必须保持 token 空间对应、处理不同长宽比和真实 LoRA rank。
- alpha 从0开始，初始化严格复现 M4；U 采用非零小随机初始化。alpha 与 U 不能同时全零，否则梯度可能同时阻断。
- 只在 image token 上调节；文本与 timestep 路径不受空间 map 的错误广播影响。
- 不再同时保留原读出残差作为第二条未经消融的强语义通道；C0/C1 使用同一条件结构。
- 学生 LoRA、条件投影、alpha、可靠性门控联合训练；主干、VAE、监督教师冻结。

这里“更顺滑”指语义改变具体低秩编辑通道，并由同一图像重建目标训练。不能仅凭结构断言其效果优于残差注入。

### 4.2 可靠性目标来自实际编辑收益

单纯的 Qwen 特征相似度或 DoLP 不能作为“语义正确性”标签。第一版将可靠性定义为：在当前学生权重下，该条件在此区域是否实际降低 GT 误差。

每8个更新进行一次额外 no-grad 校准前向，分别强制语义调节关闭、完全开启，得到当前学生的 T0/T1。二者必须使用同一时刻 LoRA、同一图、同一 VAE latent；不能拿固定旧 M4 的输出充当当前关闭语义的 T0。

$$
e(Y,G;x)=\operatorname{LocalMean}\left(|Y-G|+\eta |\nabla Y-\nabla G|\right)(x)
$$

$$
\delta(x)=\operatorname{stopgrad}\left(e(T_0,GT;x)-e(T_1,GT;x)\right)
$$

$$
y(x)=\sigma\left(\frac{\delta(x)}{\tau}\right),\qquad w(x)=\min\left(1,\frac{|\delta(x)|}{\tau}\right)
$$

$$
L_{reliability}=\frac{\sum_x w(x)\,BCE(g(x),y(x))}{\sum_x w(x)+\epsilon}
$$

- 正delta鼓励使用语义，负delta抑制错误条件；接近0的无明确收益区域降低校准权重。
- T1必须强制完整条件且不依赖待训练g，否则“把门关掉→差异变小”会污染标签。
- 校准标签与特征均 stop-gradient，仅更新可靠性头，不能通过修改候选输出来操纵自身标签。
- 主任务仍对实际门控输出计算重建、偏振一致性和现有语义/纹理损失；不能用可靠性损失替代重建。
- 第一个epoch正常联合编辑，之后每8更新校准一次。tau用训练误差尺度确定并写入配置；不看测试集调阈值。
- BCE系数先限制其对门控参数的梯度范数不超过主任务的10%，记录实测值。仅作起始设置，不能保证最优。
- 训练中另记门控分布、正常/错误条件的误差改善率，以及关闭语义时的性能。若全部关闭且无收益，必须报告条件路径失效，不能视作成功的语义利用。

测试时只有 I→C→g→编辑一次前向，不执行GT对照，不需要GT，也不依赖教师。这里g是学习的编辑收益预测；没有独立校准验证之前，不能称作可信的认知概率。

### 4.3 错误条件训练，不破坏 GT

第一个epoch后，10%的训练样本扰动语义条件，GT始终保持正确。每个被扰动样本只替换10%–30%空间区域，来源为训练集中其他拍摄组，或做局部位置错移；记录 donor、区域和随机种子。错误条件使用同一基础网络与同一C处理路径，不带额外可被识别的来源标志。

- 不再错配任何 GT。
- 不使用验证/测试图作为 donor。
- 按token空间网格处理不同长宽比；避免只靠异常数值范围识别伪条件。
- 正常条件是主要数据，不能因错误条件训练导致正常语义也被忽略。
- “错误条件下变稳健”只代表识别该类条件不一致，不能直接等同于理解汽车/玻璃/文字的物体身份。

### 4.4 最小对照矩阵

| 组别 | 结构 | 可靠性监督 | 条件扰动 | 预算 |
|---|---|---|---|---|
| B4 | 原 SMA + 可训练 LoRA | 无 | 无 | 4 epoch /204更新 |
| C0 | 语义条件 LoRA | 无，g固定1 | 无 | 4 epoch /204更新 |
| C1 | 与C0相同 | 有 | 无 | 4 epoch /204更新 |
| C2（C1有效再做） | 与C1相同 | 有 | 10%样本局部扰动 | 4 epoch /204更新 |

C0/C1都从相同M4、相同预训练记忆和相同新模块初始化出发，不能让C1从已训练C0续训。额外校准前向不增加优化更新数，但增加计算成本，需同时报告墙钟/GPU时长，不能只用epoch宣称完全同计算预算。

### 4.5 判定标准

优先看验证集选择的模型能否同时改善封存测试/real20的重建和结构指标；单独语义loss降低不算成功。还需报告：

1. 正常条件相对关闭条件的收益，证明语义被有效使用。
2. 错误条件相对正常条件的性能下降，以及门控是否相应降低。
3. 低变化区域错误改动、文字/边缘误差与新增结构示例，所有ROI在看结果前固定。
4. 语义干预确实改变编辑输出，但不会在未改区域普遍增加误差。
5. 负结果如实保留；不将注意力热图或门控图当作语义理解正确性的直接证据。

## 5. 本轮执行范围与产物

本轮实现并运行B4；C只完成设计。B的脚本为 `scripts/train_sma_joint_b.sh`，参数 `EPOCHS`或位置参数可调，默认4。正式产物 `runs/sma_joint_b_e4/`，试跑与正式目录完全分离。只保留best/latest完整联合权重和评价记录。

## 6. 实现补充

- M4 LoRA 实际包含852,180,992个可训练参数（约3.25GiB FP32），读取模块4,610,050参数。资源设计以实际数值为准。
- 旧的预训练 `memory.safetensors` 曾被清理。本轮从SMA50 best/latest中提取完全相同的冻结PCA/记忆张量，再按原预训练代码seed2026重建fresh readers。重建文件与自身张量逐一核对，另记录SHA；不声称重建文件序列化字节与已删除原文件相同。
- 解冻LoRA后，第37层也进入激活检查点路径。修复 Runtime：原始前向将Q37产生的detached memory传递给Q39/Q41；反向重算使用各自捕获的独立scope，避免教师/另一分支污染。
- 理论背景：[ControlNet](https://arxiv.org/abs/2302.05543)、[IP-Adapter](https://arxiv.org/abs/2308.06721)表明冻结主干仍可通过条件模块影响输出；它们不能证明本项目必须冻结或必须解冻，也不能替代B/C消融。
