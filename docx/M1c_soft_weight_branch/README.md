# M1c：DoLP + DINO 差异软权重位置实验

## 问题和设置

M1b 的硬 DoLP 蒙版在 10% 和 30% 语义梯度起点校准下都没有稳定胜出。本实验只检验新的**训练监督位置**能否改善效果；不修改 Qwen/WindowSeat 主干、Stage 2 初始 LoRA、基础损失、训练集和测试输入。三组均从同一 Stage 2 权重重新训练，50 张训练图 × 2 epoch = **100 次优化更新**，种子 2026，学习率 `5e-6`。验证图仍是 11、12、17，推理时只输入待处理 RGB 图。

| 组 | 训练损失 |
|---|---|
| A `base` | 原 Stage 2 基础损失 |
| B `soft` | 基础损失 + 连续软权重的 DINO(pred,GT) patch 余弦损失 |
| C `shift` | 与 B 完全相同的权重数值，按样本固定环形平移后加入同一语义损失 |

## 权重构造

冻结 `facebook/dinov2-small` 固定版本 `ed25f3a31f01632728cabb09d1542f84ab7b0056` 的第 6 层。训练前只对 **50 张训练图** 提取 `DINO(I)` 与 `DINO(GT)` 的 24×32 patch 特征；各位置的差异是 `1 − cosine`，按该图 patch 的 10%/90% 分位数缩放到 `[0,1]`。同时把配准的 8 位 DoLP 图用面积平均降至 24×32 并缩放到 `[0,1]`。

`raw = 0.25 + 0.75 × (DoLP + DINO差异)/2`；每张图除以自身均值，得到均值为 1、全位置非零的连续权重。训练翻转时权重图一起翻转。`DINO(I,GT)` 和 DoLP **只用于训练期生成固定权重**；验证图不生成权重，推理不使用 GT/DoLP。语义项仍是对完整图像编码后计算 `DINO(pred,GT)` patch 余弦距离，再用权重求平均。没有对 DINO 输入直接裁剪或遮罩。

C 组对每张图进行确定性环形位移（纵向 6–18 patch、横向 8–24 patch），保留每一个权重值、总和和大部分局部平滑结构，但改变高权重与原图内容的对应位置。边界处因环绕会出现接缝，因此 C 是位置对照，不是完全相同的空间先验。

在固定训练图 13、相同 Stage 2 初始权重和随机种子上，重新校准语义系数，使起点的 `||λ∇pred L_sem|| / ||∇pred L_base|| ≈ 0.10`。训练过程中逐步记录该比值、两个预测梯度的余弦和范数；10% 是起点目标，不保证每步都是 10%。三组 B/C 使用同一个 λ。

准备阶段实测 `λ = 0.003385286087331848`，图 13 的基础项和未加权语义项预测梯度范数分别为 `0.0015140712494030595`、`0.04472506046295166`。在真实软图的一步试跑中，模型完成前向、反向、优化与验证；第 1 步语义/基础预测梯度范数比为 `0.08195`，说明固定系数下比例会随样本变化。一步试跑没有保存 LoRA，不能用来判断效果。

## 运行

服务器执行 `./bin/xuke` 打开新 bash 后：

```bash
cd /share/linmingheng-local/xuke/RMagNet
M1C_MODEL_GPU=2 M1C_GPUS=2,3 OMP_NUM_THREADS=4 bash scripts/run_m1c.sh all
```

脚本依次生成 50 张软图、校准 λ、训练 A/B/C、评测。代码和虚拟环境都在个人目录；不使用 Docker。缓存、临时文件、权重和结果也在 `/share/linmingheng-local/xuke`。后台运行时用 `nohup` 调用该脚本，主日志保存到 `runs/m1c/m1c.console.log`，各组日志与模型在 `runs/m1c/probe_e2/`。`DONE.json` 必须显示每组 2 epoch / 100 steps；遇到已有完整组或非空未完成目录时脚本停止，不会覆盖权重。

评测对**保存后的 8 位 PNG**计算逐图与平均 PSNR、SSIM、蒙版内 PSNR/L1、蒙版外 L1。评测蒙版沿用 M1b 阈值，仅用于统一口径。比较 B−A 和 B−C，逐张检查文字、细纹理、新增物体。三张验证图和单个种子只能提供方向性证据；B 胜过 C 也只支持权重位置有用，不能单独证明模型理解了真实反射界面。
